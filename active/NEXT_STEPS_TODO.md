- targeted phone, email, contact form, referral, and selective in-person outreach;
- disciplined follow-up.

Suggested loop:

```text
prospect
→ personalized contact
→ short specific review
→ conversation
→ proposal
→ agreement + deposit/payment
→ delivery
→ launch/handoff
→ real review/testimonial when earned
→ referral
```

- [ ] Start outreach.

- [ ] Track conversion at each stage.

Diagnostic rules:

- low response -> targeting / opening message;
- responses but few conversations -> value proposition;
- conversations but no closes -> proof / trust / pricing / proposal;
- sales -> repeat the working path.
